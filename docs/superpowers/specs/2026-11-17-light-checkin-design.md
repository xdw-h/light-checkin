# 轻一点：手机减重打卡设计

日期：2026-11-17

## 目标与交付
创建手机优先的中文 PWA，部署至 GitHub Pages；无需账号、后台或付费 API。源代码单独保存于 D:\create\light-checkin。首版默认参数为男性、1997 年 8 月出生、身高 173 cm、起始体重 72.5 kg、目标 65 kg。参数仅保存在浏览器，不将健康记录提交到 GitHub。

## 页面与交互
- 今日：日期切换、体重录入（界面默认斤，可切换公斤）、六项习惯打卡、运动分钟和睡眠小时、简短备注、完成进度。允许补记，禁止记录未来日期。输入后自动保存并反馈保存状态。
- 趋势：真实记录折线、近七日平均体重、与上一个七日窗口对比、目标进度、历史记录；无数据时展示空状态，不伪造记录。称重不是每天必做任务。
- 计划：每天约 1800～2000 千卡和 90～110 g 蛋白质为可调整参考；三餐示例；每坐 60 分钟活动 3～5 分钟；第一周快走 20 分钟、第二周 30 分钟，每周 5 次；力量训练每周 2 次；睡眠 7～9 小时；每 2～3 周按趋势调整。
- 教学：坐站蹲、靠墙俯卧撑、弹力带划船，列出起始姿势、动作步骤、呼吸、常见错误和训练组次。GPT 生成一张分区教学图，注明 AI 示意，疼痛时停止，避免宣称图片为医学认证。
- 设置：修改身高、起始体重、目标、计划开始日期；JSON 备份导出及校验后导入。导入先展示记录数量与覆盖规则，经确认后替换；清空数据二次确认。

## 存储与离线
以 localStorage 保存版本化数据；捕获存储异常并提示备份。日期键采用设备本地 YYYY-MM-DD；时间展示统一格式，禁止直接展示 ISO 字符串。导入检查结构、日期、数值范围和备注长度，拒绝无效备份且不修改现有数据。备注只通过文本节点渲染。
使用 manifest、独立图标和 service worker 缓存静态资源。首次联网加载成功后可离线使用。GitHub 项目子路径下使用相对资源路径，无 SPA history 路由依赖。iPhone 通过 Safari 分享菜单添加到主屏幕；不承诺系统后台定时提醒。浏览器清理、换设备和切换域名不会自动迁移记录，需要手动备份。

## 实现和视觉
使用 Vite、原生 JavaScript 模块和 CSS，避免不必要的框架和图表依赖。暖白底色、绿色强调、大点击区域、底部导航、清晰空状态，桌面居中展示。统计、持久化、日期、界面按模块分离。数据随操作保存，不需要提交按钮。

## 验证和发布
验证日期与时区、斤公斤转换、周平均、无记录和重复记录、刷新保存、补打卡、恶意备注、无效备份和导入取消；检查 390px 手机布局、离线启动、GitHub Pages 子路径和全部资源响应。
创建 GitHub 仓库并发布 Pages；仓库名默认 light-checkin。发布前排除实际健康记录和任何密钥，仅提交业务源码、说明、静态图片和部署工作流。提交说明使用中文；按用户规则处理本任务 .test. 文件。未授权的服务部署、外部消息发送均不在本项目范围。
